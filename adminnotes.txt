v0.6.4.0500  (11/04)  하드코어 모드 (관리자 전용)

■ 공개 범위

  - 추가: 닉네임 입력창에 '💀 하드코어 캐릭터' 체크 카드 (체크하면 버튼이 '💀 만들기'로 바뀜). 일반 캐릭터와 시스템은 완전히 같고 아래 규칙만 다름
  - 하드코어는 일반으로 바꿀 수 없음
  - 캐릭터 카드 왼쪽 위에 '🔥 하드코어' 리본, 사망하면 '💀 사망' 리본 + 흑백 처리
■ 사망 규칙
  - 부활 전부 없음: 무료 부활물약(스테이지 시작 시 1회)·부활물약·동료 구조 모두 불가. 쓰러지는 즉시 사망 확정 (HUD 부활 버튼 숨김, 상점 부활 물약 행 숨김, R키·자동 사냥의 부활 동작도 무시)
  - 사망 순간 캐릭터 데이터에 즉시 저장(hd=사망 시각, hs=사망한 스테이지 번호) → 앱을 바로 꺼도 사망 유지. 랭킹에도 곧바로 💀 로 올림
  - 전체 화면 'YOU DIED' 화면 → [확인]을 누르면 타이틀로. 혼자 하기에서는 일반 '쓰러졌습니다' 결과창 대신 이 화면만 나옴. 협동 중에는 동료가 계속 진행 가능
  - 죽은 캐릭터는 카드가 그대로 남지만 시작·상점·마을 사용 불가. 이름 변경도 막힘. 삭제만 가능
  - 죽은 상태에서도 [정비]를 누르면 장비·펫·능력치를 읽기 전용으로 볼 수 있음 (랭킹 프로필과 같은 화면)
  - 삭제하면 그 캐릭터의 도감과 랭킹 기록도 함께 사라짐 (도감은 캐릭터별 저장). 삭제하지 않으면 랭킹에 💀 로 계속 남음 (자동 삭제 없음)

  - 다른 캐릭터와의 전달도 불가: 하드코어 캐릭터는 보낼 곳이 없음, 일반 캐릭터도 하드코어 캐릭터를 받는 곳으로 고를 수 없음. 마을 물약 우편은 자기 자신에게만 가능
  - 풍차·연구소 효과는 계정 공유 그대로. 단, 하드코어 캐릭터가 마을·연구소 비용을 낼 때는 자기 골드·조각만 사용 (보관함 골드·조각은 사용 안 됨)
