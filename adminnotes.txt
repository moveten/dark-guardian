■ 연구실 (관리자 전용 공간)
  - 추가: 상점의 구매창 아래에 '📚 연구실' 섹션 (활성화된 계정에서만 보임)
    · 문구: '어서오세요, 관리자님 환영합니다.'
    · 버튼: 📔 관리자 노트(이 파일 열람) / 📜 출입 기록(출입 기록 열람) / 🚪 나가기(관리자 권한 반납 = 연구실 비활성화, 확인창 한 번)
  - 활성화 방법: 장비 아이템 레벨 합이 0이고 캐릭터 Lv이 2인 캐릭터가, 상점에서 즉시 부활(부활물약)을 4개 구매하려다 골드가 모자라 '금화가 부족해요'가 뜰 때 관리자 비밀번호 창이 뜸 → 비밀번호(****) 입력 시 활성화
  - 적용 범위: 캐릭터별이 아니라 계정 전체 (저장 키 dkdef2.lab, 클라우드 저장에도 함께 저장되어 복구 코드로 이어받은 기기에서도 켜져 있음)
  - 비밀번호 확인: 입력값의 해시로만 비교(코드에 비밀번호 글자는 없음). 출입 기록 저장·열람은 서버(DB 함수)가 비밀번호를 한 번 더 확인
  - 비밀번호를 입력한 기기에만 비밀번호를 보관(dkdef2.cl.labpw, 클라우드 저장 제외). 복구 코드로 이어받은 기기에서는 출입 기록 열람·나가기 때 한 번 더 물어봄
■ 출입 기록 (charlogs.txt 형식)
  - 추가: 관리자 권한을 얻거나 반납하면 시간과 그 계정의 모든 캐릭터 이름을 기록
    · 획득: yyyy/MMM/dd(aaa) HH:mm:ss, 새로운 관리자가 권한을 획득하였습니다 - john, tom, jane
    · 반납: yyyy/MMM/dd(aaa) HH:mm:ss, john, tom, jane 이 관리자 권한을 반납했습니다.
    · (aaa)는 요일 한 글자(월·화·수…), MMM은 영문 월 약어(Nov)
  - 저장 위치: 정적 파일(txt)은 게임이 직접 쓸 수 없어서 서버 테이블 dd_charlog 에 쌓고, [📜 출입 기록]에서 위 형식 그대로 최신순으로 보여줌. 저장소의 charlogs.txt 로 내보내려면 요청 (현재 저장소에는 파일 없음)
  - 서버 연결이 안 되면 기기에 대기열(dkdef2.cl.labq, 최대 20건)로 남겨 뒀다가 다음에 다시 보냄. 열람 화면에는 '(전송 대기)'로 표시
  - DB: 테이블 dd_charlog(id, kind in/out, names, created_at) — 앱에서 직접 읽기/쓰기 불가(RLS), 함수 dd_lab_log(비밀번호, 종류, 이름들, 시각) / dd_lab_list(비밀번호, 개수)로만 접근. 생성 SQL은 supabase_charlog.sql (비밀번호는 ****)
■ 랭킹
  - 추가: 관리자 권한이 있으면 랭킹 탭 아래에 한 줄 더 표시 [⏰ 최근활동] [📈 미사용1] [📈 미사용2] (미사용 두 칸은 눌려도 동작 없음, 자리만 잡아 둠)
  - 추가: ⏰ 최근활동 = 랭킹 DB(dd_rank)의 updated_at 이 최근인 캐릭터 순. 캐릭터 이름 아래에 updated_at(yyyy/MMM/dd(aaa) HH:mm:ss), 오른쪽 값(rkv)에는 캐릭터 레벨
  - 최근활동은 10분 캐시를 쓰지 않고 열 때마다 새로 불러옴
■ 기록 규칙
  - 관리자 관련 추가·수정, 치트키, 미공개(요청·스테이지·캐릭터 등) 내용은 patchnotes.txt 가 아니라 이 파일(adminnotes.txt)에 기록. 한 번의 요청에 둘이 섞여 있으면 나눠서 기록 (패치노트에는 '■ 기타 - 추가: 연구실 기능이 추가되었습니다.' 정도로만)
  - 이 파일의 비밀번호는 '****'로 표시
