v0.1.1.0024  (10/12)  강령술사 신규 스킬 「영혼 융합」
==============================
■ 영혼 융합 신규 (요구 레벨 21 · 마나 25 · 재사용 40초 · 시한 소환수와 동시에 존재 가능)
  - 수호 영혼 + 포격 영혼이 둘 다 살아 있을 때만 스킬 버튼이 나타남. 융합 중에는 버튼이 켜진 채로 보이고, 다시 누르면 바로 분리(재사용 대기는 그대로)
  - 둘이 하나로 합쳐 (10+0.3×Lv)초간 [융합 영혼]이 되어 적진을 휩쓸고 다님 (Lv10 = 13초)
  - 생명력 : 내 최대 생명력의 (220+10×Lv)% (둘의 평균 남은 생명력 비율로 시작), 받는 피해 -50%, 4초마다 반경 200 도발
  - 지속 피해 : 0.5초마다 반경 105 안의 적에게 6+4×Lv
  - 영혼탄 : 2초마다 가까운 적에게 3발 (Lv8마다 +1발, 최대 6발), 발당 16+10×Lv
  - 휩쓸기 : 4초마다 반경 150 범위 피해 50+22×Lv + 밀치기
  - 소환수 피해 옵션·영혼 연결·공명·처형 표식 등 소환수 공통 효과는 그대로 적용
  - 시간이 끝나거나 다시 누르면 둘로 돌아오며 융합 영혼의 남은 생명력 비율을 이어받음 (쓰러지면 생명력 20%로 분리)
  - 융합 중에는 수호/포격 영혼을 새로 부를 수 없음 · 영혼 폭발은 영구 소환수가 없어 사용 불가
  - 수호 영혼·포격 영혼 스킬 3레벨마다 영혼 융합 스킬 레벨 +1 (시너지)
  - 전투력 계산에 영혼 융합 반영
  - (참고) 융합 영혼 전용 이미지 mn_fusion.png 가 없으면 수호+포격 영혼 그림을 겹쳐서 표시

v0.1.1.0018  (10/12)  신규 직업 강령술사 (소환수 중심)
==============================
■ 강령술사 신규 (캐릭터 생성에서 4번째 카드, 랭킹 DB도 대응)
  - 기본 능력치 : 힘 10 / 민첩 15 / 체력 20 / 에너지 30 · 기본 생명력 56 · 기본 마나 18 · 원거리
  - 시작 무기 참나무 지팡이, 보조 장비 "영혼 등불" 계열 (혼등 / 영혼 등불 / 망령의 등불), 전용 유니크 "망자의 지팡이"(처치 시 마나 6 회복, 재사용 대기 -10%)
  - 전투력 보정 ×0.8 (마법사 ×0.75 / 전사 ×1 / 팔라딘 ×1.2 사이)
■ 소환수 규칙
  - 영구 소환수(수호/포격 영혼) : 스테이지 시작 시 무료 소환. 쓰러지면 스킬로 다시 소환(재사용 대기 8초)
  - 시한 소환수(거인/용령) : 동시에 하나만 존재. 새로 부르면 기존 것은 사라짐
  - 소환수 피해 = 스킬 기본 피해 × (1 + 영혼 연결 4%×Lv) × (1 + 소환수 피해 옵션%) × (군주 강림 중 1.4)
  - 몬스터가 소환수도 공격 대상으로 삼음 (소환수 방어력 = 내 방어력 ×1.2, 시한 소환수는 받는 피해 -50%)
  - 협동 : 호스트 화면에서만 몬스터가 소환수를 공격. 게스트의 소환수는 호스트 몬스터에게 맞지 않음, 동료 소환수는 위치만 보임
■ 스킬 (요구 레벨 / 마나 / 재사용)
  - 혼불 Lv1 / 3 / 0.8초 : 발당 14+10×Lv, 7레벨 2발·14레벨 3발(발당 ×0.7 / ×0.55). 적중 시 소환수 생명력 2% 회복
  - 영혼 연결 Lv3 (패시브) : 소환수 피해 +4%×Lv, 소환수 받는 피해 -1.5%×Lv (최대 30%)
  - 수호 영혼 Lv6 / 12 / 8초 : 생명력 = 내 최대치의 80%+5%×Lv, 1.2초마다 14+10×Lv 피해, 4초마다 170 범위 3초 도발
  - 포격 영혼 Lv9 / 14 / 8초 : 생명력 50%+3%×Lv, 1.8초마다 마법탄(18+12×Lv, 7·14레벨 +1발)
  - 영혼 공명 Lv12 (오라) : 소환수 공격 속도 +2%×Lv(최대 +40%), 소환수 준 피해의 3%+0.2%×Lv 만큼 내 생명력 회복
  - 영혼 폭발 Lv15 / 16 / 12초 : 영구 소환수 폭파, 범위 피해 100+40×Lv + 소환수 현재 생명력 50%, 1초 기절(우두머리 면역). 3초 뒤 생명력 50%로 복귀
  - 처형 명령 Lv18 / 12 / 18초 : 8초 표식. 소환수 집중 공격 + 공격 속도 +30%, 표식 적 받는 피해 +(20%+3%×Lv)
  - 고대 거인 Lv24 / 30 / 45초 : (18+0.5×Lv)초 소환, 생명력 300%+15%×Lv, 1.5초마다 범위 피해 120+45×Lv, 4초마다 도발
  - 영혼 서약 Lv30 / 20 / 25초 : 8초간 받는 피해의 (50%+2%×Lv, 최대 80%)를 소환수가 대신 받음
  - 영혼 군주 강림 Lv99 (궁극기) / 60 / 90초 : 15초간 영혼 용령 소환(생명력 400%+20%×Lv), 0.5초마다 부채꼴 범위 피해 100+30×Lv, 모든 소환수 피해 +40%. 거인은 사라짐
■ 신규 아이템 옵션 (강령술사 전용)
  - 소환수 피해 +% : 무기·목걸이·반지·투구, 수치 6~(14+2×등급) %
  - 소환수 생명력 +% : 갑옷·투구·목걸이·방패, 수치 8~(20+2×등급) %

  - 보랏빛 폭발(노바) : ×1.2 → ×1.56
  - 집결 공격(함께 맞아 나눔) : 1인 ×1.9 → ×2.47 / 협동 ×3.6 → ×4.68
  - 내려찍기 : ×1.6 → ×2.08
  - 돌진 : ×1.6 → ×2.08
  - 변화 없음 : 반격 태세, 체력 반깎기(피해 없음), 일반 몬스터·정예 몬스터 기술
