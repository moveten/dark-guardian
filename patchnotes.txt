v0.1.1.0016  (10/12)  마법사 감전 / 서리 고리 / 슬롯
==============================
■ 연쇄 번개 → ⚡감전 신규
  - 연쇄 번개에 맞은 적은 (4 + 0.15×스킬레벨)초간 감전 (Lv10 = 5.5초, 우두머리 포함)
  - 감전 중인 적에게 화염·냉기 스킬(화염구·유성·대재앙·서리 고리·눈보라)을 맞히면 피해 ×4/3 (+33%)
  - 일반공격·번개 스킬에는 적용 안 됨. 감전 상태는 시전한 본인 화면 기준으로 적용 (동료 감전과는 합산 안 됨)
■ 서리 고리
  - 범위 +30% (반경 160 → 208, 스킬 범위 옵션 별도 적용)
  - 피해 +30% : (14+10×레벨) → ×1.3
  - 연타 : 1연타 → 레벨 7 이상 2연타 / 레벨 14 이상 3연타 (0.28초 간격, 연타 피해 배율 100% / 70% / 55% — 화염구·망치와 동일)
  - 감속은 첫 타에만 적용
  - 전투력(CP) 계산에도 반영
■ 캐릭터 슬롯 5개 → 10개
■ 가방에서 아이템을 고르면 나오던 "바꾸면 생명력/방어력/공격력 +N" 설명 제거 (착용 중 아이템 비교창은 그대로)

v0.1.1.0012  (10/12)  올스킬 확률 하향
==============================
■ 올스킬(모든 스킬 +N) 장착 부위: 목걸이·투구·무기·반지·갑옷 (방패 제외, 변경 없음)
■ 올스킬이 붙을 확률
  - 유니크 : 약 7% (추정) → 약 10% 시도, 방패 제외 평균 약 8%
  - 레어   : 약 1% (추정) → 3.5%
  - 매직   : 약 1% (추정) → 1.2%
■ 올스킬 +2가 나올 확률 (나머지는 +1)
  - 유니크 35% → 20%
  - 레어   35% → 8%
  - 매직   0% (항상 +1)
■ 유니크는 올스킬 또는 스킬 옵션(직업/개별) 중 하나만 붙어요 (동시 불가)

v0.1.1.0011  (10/12)  스킬 옵션 확률 재설계 / UI
==============================
■ 스킬 옵션을 일반 옵션과 분리해서 따로 굴림 (이전: 일반 옵션 21종 중 하나로 섞여서 레어는 올스킬 거의 안 나옴)
■ 직업 스킬(+N 직업 스킬) / 개별 스킬(+N 스킬이름) 확률
  - 유니크 : 약 28% (올스킬과 동시 불가)
  - 레어   : 약 12% / 올스킬과 둘 다 붙는 경우는 매우 드묾 (약 0.3%)
  - 매직   : 약 5%
■ 어느 직업의 스킬이든 붙을 수 있음 (직업 전용 아이템은 그 직업 스킬만)
■ 인벤 아이템 레벨 비교 표시(▲▼＝)를 작게 줄임 (글자 14px → 11.5px)

v0.1.1.0010  (10/12)  강화 버그 수정
==============================
■ 강화 성공 확률은 그대로 (아래 표 참고). 코드 점검 결과 확률 계산은 정상.
■ 강화창을 열어 둔 사이 자동합성/자동판매로 가방이 바뀌면, 골드·재료를 쓰지 않고 강화를 취소하도록 수정

[참고] 강화 확률표 : 성공률 = 100 − 8×(목표단계−1)%  (최소 5%)
  +1:100%  +2:92%  +3:84%  +4:76%  +5:68%  +6:60%  +7:52%  +8:44%  +9:36%  +10:28%
  최대 +10 / 재료 : 같은 등급 아이템 (목표단계)개 / 실패 시 재료·골드 소모, 단계 유지
  강화 비용 = (1000 + 1000×목표단계) × 1.5 골드 (0.1.1.0005에서 ×1.5 상향)

v0.1.1.0005 ~ 0007  합성 / 보조무기 / 레벨 비교
==============================
■ 아이템 합성 : 같은 등급 5개 → 한 단계 위 등급 랜덤 1개 (일반→매직→레어→유니크)
  - 결과 아이템 레벨 = 재료 평균 + 0~3, 단 "장착 중인 장비의 강화 제외 최고 레벨" 이하
  - 잠금·강화 아이템은 재료로 안 씀 / 자동합성은 줍는 즉시 작동
■ 강화 비용 ×1.5 (예: +1강 2,000 → 3,000 골드)
■ 전사 보조무기(레어 이상): "스킬 범위 +N%" 옵션 고정 부여 (레어 +4~7%, 유니크 +7~10%) — 범위 옵션 합계 상한 15%
■ 직업 전용 아이템 표기("✔ 전사 전용 보조무기" 등), 보조무기 아이콘에 "보조" 글자
■ 구버전 방패를 전사·마법사 보조장비로 자동 변환
■ 보스 "다음 스테이지급 아이템 드랍"은 추가했다가 요청으로 완전히 제거 (드랍 확률은 원래대로)
