새 직업 음성을 넣으면 index.html 의 VOXC 배열에 직업 코드를 추가해야 나와요.

audio/sfx/<소리>_<번호>.mp3 : 효과음 (Kenney CC0 — Impact Sounds · RPG Audio · Interface Sounds 를 가공). index.html 의 SFXN 에 '소리:변형 개수'로 적힌 것만 불러오고, 목록에 없는 소리는 자동 생성 소리를 써요.
